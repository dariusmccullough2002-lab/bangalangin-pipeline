# Frozen analysis protocol

Written before inspecting test results. All work is offline; no production changes.

1. Compare each player's 2024–2026 Savant skills, fresh Kodo evidence and monthly bat tracking. Expected statistics describe the contact recorded; they are not future projections. Kodo/Savant overlap is one source family. Verify player IDs, year, level and aligned rates before numerical use.
2. Run league-category counterfactuals at equal 600 PA and at inherited forecast PA. Compare observed latest-season rates, expected-quality latest-season rates, and the existing rate forecast. These are sensitivity scenarios, not predictions or matchup-win estimates. Do not infer HR from xSLG.
3. Test the rate-estimation assumption across other hitters: Savant expected-stat exports 2015–2026 joined to official MLB annual components by MLBAM and year. Exclude Vargas and Naylor from model selection and aggregate evaluation. Restrict to current/next-year positive samples (latest >=150 PA, target >=250 PA); this is a conditional rate test, not an attrition/workload test.
4. Reproduce the active pre-aging four-year estimator: nominal .1/.2/.3/.4 season weights normalized over available observed years, plus the frozen 100-PA league prior from qualified 2010–2012 hitters. Evaluate next-year AVG and SLG. Cohort aging and playing time are held outside this test.
5. Compare fixed quality-family weights 0, .10, .25, .50, .75 and 1.0. Sample shrinkage is latest PA/(latest PA+100). Blend xBA/xSLG into the same base rate forecast. Choose one weight on 2019–2023 targets, excluding the shortened 2020 season, by mean of AVG/SLG MAE relative to baseline training MAE. Report every weight on held-out 2024–2026 targets. Never select a weight from a named trade outcome or held-out performance.
6. Define breakout/decline groups before testing: >=200 PA in the latest two observed seasons and last-year xSLG change >=+.050 or <=-.050. Report group errors and sample sizes, all calendar-year errors, and paired player-cluster bootstrap intervals for held-out MAE differences. The same player's repeated target years remain in one bootstrap cluster.
7. Check missing data, duplicate identities, coherent rates, chronological joins and source drift. Report unavailable injury-conditioned forecasting, historical within-season expected-quality snapshots, lineup outcomes and 2027 actuals as blocked checks.
