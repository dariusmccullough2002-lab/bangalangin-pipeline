# Reproduction

Read Architecture_Workload_Review.md, PROTOCOL.md and PROTOCOL_AMENDMENT.md first. All work is experimental; no production model is imported into the application.

Inputs are the unchanged recovery model root, frozen catalog, parent audit scripts, debut ledger/source caches, Historical_Cases.json and Debut_Chronological_Cases.json. The prior checkpoint carries compressed copies; decompress them next to the scripts if needed. Python dependencies: numpy, pandas, scipy, scikit-learn; use one numerical thread for deterministic fitting. ROOT below points to the recovered BangaLangin_V23C directory; CAT is the exact beta-unpacked.json catalog. Saved model-source hashes and catalog SHA are retained in the audit outputs.

Run scripts from this folder with ROOT and CAT arguments:

```bash
python opportunity_models.py ROOT CAT
python mechanism_checks.py ROOT CAT
python pipeline_2020_audit.py ROOT CAT
python verified_availability.py ROOT CAT
python role_aware.py ROOT CAT
python quality_aware.py ROOT CAT
python additional_anchors.py ROOT CAT
python integrity_checks.py CAT
```

The availability script reuses cached individual official transaction responses. Do not repeat bulk collection. Previously validated innings caches and older failed-candidate evaluations are not regenerated by these commands. Scripts reuse the preserved exact case lists.

rebuild_current.py and rebuild_role_current.py can refresh only current sensitivity calculations after an accounting change, without historical refitting. refresh_leverage_scores.py updates saved leverage scores from predictions without refitting. before-leverage-guard contains superseded experimental current snapshots; use top-level outputs for review. Each validation JSON includes subgroup scores/date manifests; .json.gz files contain per-case or per-player records. Strongest_Direction_Material_Impact.csv is the full material impact table for the strongest current research direction, not a production release diff.

Main application, catalog, owners, picks, saved trades, header and production remain unchanged. No numerical deployment is authorized by this package.
